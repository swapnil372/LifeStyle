# LIFESTYLE
#### Video Demo: https://www.youtube.com/watch?v=X-2TQtSBYkc
#### Description:
The LifeStyle website offers the user with features, like adding options for tasks, a pomodoro timer, and small quick note and a motivational quote.

The website has been created with HTML, CSS and Javascript, with only client-side interface. Whatever the user enters here is NOT submitted to the developer. Two parts appear side by side in the website. The website can be used in any device using any web browser. The website uses Javascript in major part to save the tasks, create the pomodoro timer. The developer used Chatgpt for many parts of the website. The website is in dark mode for giving an aesthetic experience to the users. A maximum width has been set for the main part of the website and everything has been aligned to the center so that the website can be used in any web browser of a device of any dimension. Each of the parts gets a little bit larger when it is active or used by the user. Each of the buttons also get a little different color when the user hovers over it. When the buttons ar active or pressed, the buttons get a little smaller than the regular size of the button. The tasks and the buttons have got shadows but the buttons only show these shadows when the user hovers over them. The website is run by using Github and can only be edited by the developer. However the user can change the website's HTML, CSS and Javascript in the inspect option. But this will be applicable to the user until he refreshes the page when the website is loaded back to the main version.

The first part is My Tasks. The user cacn add a new task by clicking on the Add Task button. The list of tasks can be cleared up with the Clear List button. When a task is added, it is automatically saved to the user's browser local storage. And so, when the page is reloaded, the tasks are not vanished and the website appears just like it was when it was closed or refreshed. There is a checkbox, which the user can click when he has completed the task. The task gets striked through when the checkbox is pressed. The task also gets disabled when the checkbox is marked, so the user cannot edit them. This can be undone by clicking on the checkbox again. When the list is cleared, this gets reset and everything is removed from the user's browser local storage except the note he saved. The tasks can be scrolled down to view the other tasks. The new task is entered at the very top of all the tasks. The text in this part when there is no task appears which disappears once the user adds the very first task. When the user clears the list of tasks this text appears again.

The second part is the Pomodoro Timer. This is actually a timer that the user can set while studying or working. The timer is started by clicking the Start button. When the timer is running, the Pause button appears in place of the Start button. By clicking the pause button the time can be stopped. The timer can also be reset by clicking on the Reset button. When the timer counts to zero, then a prompt appears to the user. 

The third part is the note taking part, where the title is "What's on your mind?". The user can keep a note of atmost 200 words here. When the user clicks anywhere else, the note gets automatically saved to the user's browser local storage. The page can be refreshed but still the previous records are conserved. There is a Save button below the textarea. The Save button will submit the form and refresh the page. The user can generate a timer of minimum of five minutes. The maximum time has no limit. The user can use the browser feature of arrows to increase or decrease the time. However, when the timer is running, the inputs for the timer have been disabled so that the user cannot edit them or take any unethical means.


The fourth part is where a motivational quote appears every time the user refreshes. The quote is generated at random from a list of 50 quotes. The font in this part is different from the regular font. It gets some cursived font if available by the browser. Otherwise, another default font has been set. 


There is a footer below the website which bears the developers name.
